# 🚦 Smart Traffic Light System

## 📌 Project Overview

The Smart Traffic Light System is an Arduino Uno-based prototype designed to demonstrate automated traffic signal management. The system uses sensors to detect vehicles and controls traffic lights and a servo motor according to the detected traffic conditions.

This project demonstrates how sensors, a microcontroller, LEDs, and a servo motor can be combined to create a simple smart traffic management system.

## 🎯 Objectives

- To demonstrate automatic traffic signal control.
- To detect vehicles using IR sensors.
- To control Red, Yellow, and Green traffic LEDs.
- To demonstrate automated barrier control using a servo motor.
- To understand the practical use of Arduino in traffic management.

## 🔧 Components Used

- Arduino Uno
- IR Sensors
- Red LED
- Yellow LED
- Green LED
- Servo Motor
- Buzzer
- Resistors
- Breadboard
- Jumper Wires
- Power Supply

## ⚙️ Working Principle

The IR sensors detect the presence of vehicles on the road. The sensor signals are sent to the Arduino Uno, which processes the input and controls the traffic signal LEDs.

The Red, Yellow, and Green LEDs represent the traffic signal states. A servo motor is used to demonstrate an automated traffic barrier.

The system provides a simple model of how sensor-based automation can be used for traffic management.
